# 坦克大战 · 传统民间策略棋

一款基于 React + TypeScript + Vite 的网页棋类游戏，将传统民间“夹击棋”（又称坦克棋）数字化，并配以木纹棋盘、坦克造型棋子、Web Audio 合成音效与爆炸特效。

红黑双方各执坦克，通过走子把对方棋子夹在中间即可消灭。规则简单、上手快，一局几分钟。

---

## 游戏规则

- **棋盘**：在交叉点与方格中心之间的连线上行棋，棋盘呈“米”字格拓扑（横、竖、斜线均可走）。
- **走子**：
  - 选中己方坦克后，棋盘会显示绿色可落点提示。
  - 横竖方向只能沿主网格线移动（一次走一格的整数距离）。
  - 斜线方向可从任意点移动到相邻的斜线交叉点。
  - 路径上不能有其他棋子阻挡，落点必须为空。
- **夹击吃子**：当己方两枚棋子在同一直线上紧紧夹住对方一枚或多枚棋子时（例如 `红-黑-红` 或 `红-黑黑-红`），被夹住的对方棋子全部被消灭。一步走子可在多个方向同时触发吃子。
- **获胜条件**：吃掉对方棋子，直到对方剩余少于 2 枚即获胜。
- **先手**：红方先行。

> 提示：只有“你主动走子去夹住对方”才会吃子；对方主动走进你两子中间不会被吃。

---

## 主要特性

- 🎨 **精致视觉**：木纹质感棋盘、带炮塔/履带/五角星徽记的坦克棋子、上一步走子标记、星位提示。
- 🔊 **合成音效**：基于 Web Audio API 实时合成，无需任何音频文件——选子、移动、夹击爆炸、悔棋、无效操作、胜利号角各有专属音效，可一键开关。
- 💥 **动态特效**：吃子时在目标位置播放爆炸（闪光、冲击波、飞溅粒子、上升烟雾）；无效落子时棋盘抖动提示；棋子移动带回弹缓动。
- 📊 **战况面板**：实时显示双方存活/阵亡数、回合切换徽章、对战记录（最新在前，吃子高亮）。
- ↩️ **悔棋 / 新游戏**：随时回退上一步或重开一局。
- 🏆 **胜利动画**：彩带飘落 + 奖杯弹跳 + 比分展示。

## 本地运行

**前置要求**：Node.js（建议 18+）

```bash
# 1. 安装依赖（首次或依赖更新时）
npm install

# 2. 启动开发服务器
npm run dev
```

启动后访问终端提示的地址（默认 **http://localhost:3000**）即可开玩。

> 注：因浏览器限制，页面首次需要用户点击交互后才会播放音效。

### 构建与预览生产版本

```bash
npm run build     # 输出到 dist/
npm run preview   # 本地预览生产构建
```

## 技术栈

- **React 19** + **TypeScript** — 组件化界面与类型安全
- **Vite 6** — 开发服务器与构建工具
- **Tailwind CSS 3**（本地 PostCSS 构建，无外网依赖）— 样式
- **lucide-react** — 图标
- **Web Audio API** — 运行时合成音效
- **SVG** — 棋盘、棋子与特效绘制

### 核心逻辑说明

棋盘使用 9×9（索引 0–8）的坐标空间：

- **偶数坐标**（0, 2, 4…）为主网格交叉点。
- **奇数坐标**（1, 3, 5…）为方格中心。
- 仅当 `col % 2 === row % 2` 时该点为合法落子点（“米”字格拓扑）。

走子合法性校验在 `App.tsx` 的 `isValidMove` 中实现；夹击吃子判定在 `checkCaptures` 中沿 8 个方向向外探测，遇到“对方棋子连续 + 己方棋子收尾”即判定吃子。
