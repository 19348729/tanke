# 坦克大战 · Godot 版

原网页版（React + SVG）用 **Godot 4.7** 重写成的原生游戏，规则完全一致，并加入了人机对战等改进。

## 运行

```bash
# 安装 Godot（已装可跳过）
brew install --cask godot

# 直接运行游戏
godot --path godot

# 用编辑器打开项目
godot -e --path godot
```

也可以打开 Godot，在项目管理器里"导入"本目录的 `project.godot`。

## 相比网页版的改进

| 方面 | 网页版 | Godot 版 |
| --- | --- | --- |
| 对战模式 | 仅双人同屏 | **人机对战（执红 / 执黑）** + 双人对战 |
| 电脑 AI | 无 | Alpha-Beta 迭代加深搜索 + 吃子静态搜索，后台线程计算不卡界面 |
| AI 配置 | 无 | 6 个预设（简单 / 普通 / 困难 + 激进型 / 稳健型 / 新手型）+ 自定义面板，9 项参数可调并自动保存 |
| 提示 | 无 | 「提示」按钮用 AI 推荐一步，蓝色路径标出 |
| 胜负判定 | 只判少于 2 子 | 另加：**轮到一方无子可走判负**，**连续 60 步无吃子判和**（避免死局） |
| 悔棋 | 退一步 | 人机模式一次退回到玩家上一步之前；电脑思考中也能悔 |
| 记谱 | 只记主网格点，方格中心显示"斜线中心" | 统一 a–i / 1–9 坐标，棋盘四周标注 |
| 坦克动画 | 平移 | 先转向行进方向再驶出，到位后转回；悬停放大、选中旋转光圈 |
| 吃子特效 | CSS 动画 | 粒子火花 + 烟雾 + 冲击波 + 棋盘震动 |
| 快捷键 | 无 | Ctrl/⌘+Z 悔棋 · N 新游戏 · H 提示 · Esc 取消选择 |
| 其它 | — | 全屏切换；音效仍为运行时合成，无外部音频文件 |

## 电脑配置

侧栏「电脑」下拉框选预设，或点「调整」打开自定义面板（可先从任一预设载入再微调）。设置自动保存在
`user://settings.cfg`（macOS 上是 `~/Library/Application Support/Godot/app_userdata/坦克大战/`），下一步棋起生效。

| 参数 | 范围 | 作用 |
| --- | --- | --- |
| 搜索深度 | 1–8 步 | 最多往后算几步 |
| 思考时间 | 0.2–5 秒 | 每步思考上限，到时用已算完的最深结果 |
| 吃子延伸 | 0–6 步 | 算到底后继续跟进吃子交换，避免只看半步 |
| 随机性 | 0–200 | 评分随机扰动，越大越不按套路 |
| 失误率 | 0–50% | 每步按此概率随手走 |
| 进攻欲望 | 50–200 | 吃掉对方一子的价值 |
| 防守意识 | 50–200 | 保住己方一子的价值 |
| 占位意识 | 0–15 | 站主网格交叉点的加分 |
| 机动意识 | 0–5 | 周围每个空位的加分 |

进攻 ≠ 防守 时形成性格：激进型（145 / 80）愿意一换一兑子，稳健型（90 / 145）会避开。
GDScript 搜索约 2.5 万局面/秒，思考 2 秒大约算到 3–4 步；面板会在"深度设了但算不到"或权重失衡时给出提示，
侧栏也会显示电脑上一步实际算到几步。新增参数只需在 `ai_config.gd` 的 `FIELDS` 里加一行，面板滑块自动生成。

## 目录结构

```
godot/
├── project.godot        # 项目配置（Compatibility 渲染器，方便导出 Web）
├── scenes/main.tscn     # 主场景（界面由 main.gd 代码搭建）
├── scripts/
│   ├── rules.gd         # 纯规则：走子、夹击、胜负（与界面解耦）
│   ├── ai.gd            # 电脑对手（搜索）
│   ├── ai_config.gd     # 电脑参数表、预设、存档
│   ├── ai_settings_panel.gd  # 自定义电脑面板
│   ├── main.gd          # 对局流程与侧栏界面
│   ├── board_view.gd    # 棋盘绘制与点击
│   ├── tank_piece.gd    # 坦克棋子绘制与动画
│   ├── explosion.gd     # 吃子爆炸特效
│   └── sfx.gd           # 合成音效
└── tests/test_rules.gd  # 规则与 AI 自测
```

## 测试

```bash
godot --headless --path godot --script res://tests/test_rules.gd
```

覆盖走子范围、各方向夹击、"走进夹击不被吃"、胜负与和棋判定、配置校验、每个预设都能按时走出合法着法、
激进型接受 / 稳健型拒绝一换一兑子、简单对普通的自对弈能正常结束。

## 导出

在编辑器中「项目 → 导出」添加 macOS / Windows / Web / Android 预设。首次导出需按提示下载对应版本（4.7.2）的导出模板。
注：Web 导出时系统字体不可用，如需中文显示，要在 `main.gd` 的 `_build_theme()` 里换成打包进项目的中文字体文件。
